# LifeOS — Flutter (موبايل + ويب) مع قاعدة بيانات Supabase

نظام لإدارة الحياة: الرؤية ← الأهداف ← المشاريع ← المراحل ← المهام ← المخطط ← المراجعة.
تطبيق واحد يعمل على **Android وiOS والويب**، وبياناتك محفوظة في قاعدة بيانات **PostgreSQL (Supabase)** وتتزامن بين كل أجهزتك.

---

## التشغيل لأول مرة (حوالي 10 دقائق)

### 1) جهّز Flutter
ثبّت Flutter (الإصدار 3.35 أو أحدث): https://docs.flutter.dev/get-started/install
ثم تأكد أن كل شيء سليم:
```bash
flutter doctor
```

### 2) أنشئ قاعدة البيانات على Supabase (مجانًا)
1. ادخل https://supabase.com وأنشئ مشروعًا جديدًا (New project).
2. من القائمة الجانبية افتح **SQL Editor** ← **New query**.
3. انسخ محتوى الملف `supabase/schema.sql` كله والصقه، ثم اضغط **Run**.
   هذا ينشئ 18 جدولًا مع حماية **Row Level Security** (كل مستخدم يرى بياناته فقط).
4. من **Project Settings ← API** انسخ:
   - `Project URL`
   - `anon public key`
5. (اختياري أثناء التجربة) من **Authentication ← Providers ← Email** يمكنك إيقاف
   "Confirm email" حتى تدخل مباشرة بعد إنشاء الحساب.

### 3) أنشئ ملفات المنصات (Android / iOS / Web)
داخل مجلد المشروع:
```bash
flutter create . --project-name lifeos --platforms=android,ios,web
flutter pub get
```
> هذا الأمر يضيف مجلدات `android/` و`ios/` و`web/` فقط ولا يغيّر ملفات `lib/`.

**مهم لأندرويد:** افتح `android/app/src/main/AndroidManifest.xml` وأضف هذا السطر فوق `<application`:
```xml
<uses-permission android:name="android.permission.INTERNET"/>
```

### 4) شغّل التطبيق
```bash
# على الويب (Chrome)
flutter run -d chrome --dart-define=SUPABASE_URL=https://XXXX.supabase.co --dart-define=SUPABASE_ANON_KEY=eyJ...

# على موبايل متصل أو محاكي
flutter run --dart-define=SUPABASE_URL=https://XXXX.supabase.co --dart-define=SUPABASE_ANON_KEY=eyJ...
```
بديل أسهل: ضع القيمتين مباشرة كـ `defaultValue` في `lib/core/config.dart`.

أول ما تسجّل حسابك، التطبيق ينشئ لك تلقائيًا مجالات الحياة الأساسية ومراحل صندوق الأفكار وبعض التصنيفات.

### 5) النشر
```bash
flutter build web --release --dart-define=...      # ارفع مجلد build/web على Netlify / Vercel / Firebase Hosting
flutter build apk --release --dart-define=...      # ملف APK لأندرويد
flutter build ipa --release --dart-define=...      # iOS (يتطلب Mac + حساب Apple Developer)
```

## ماذا يوجد في التطبيق

| القسم | أهم ما فيه |
|---|---|
| **Dashboard** | مهام اليوم، العادات المطلوبة، التالي في الجدول، وقت التركيز، تقدم المشاريع والأهداف، توازن مجالات الحياة |
| **الرؤية والأهداف** | رؤية ← أهداف، تقدم محسوب من البيانات بجانب تقديرك اليدوي، فتح مشاريع الهدف مباشرة |
| **مجالات الحياة** | مجالات **منفصلة تمامًا** عن التصنيفات، ترتيب بالسحب، لون وأيقونة، نقل العناصر قبل الحذف |
| **المشاريع** | صفحة Workspace لكل مشروع: مراحل، مهام لكل مرحلة، **مشاريع فرعية**، **سجل ملاحظات/تعليقات**، روابط الموارد |
| **المهام** | قائمة / Board بالسحب / تقويم بإحصائيات يومية، خطوات فرعية، روابط صور وفيديو، إضافة جماعية، CSV |
| **المخطط (Planner)** | يوم (Timeline بالسحب وتغيير المدة) / أسبوع (سحب بين الأيام) / شهر / قائمة، **ملاحظات لكل موعد**، جدولة المهام المستحقة |
| **العادات** | يومي/أسبوعي/شهري مع عدد مرات، **خطوات روتين متداخلة**، Streak وأفضل سلسلة ومعدل، تسجيل الأيام السابقة |
| **تتبع الوقت** | مؤقت حي، إدخال يدوي، ملخص اليوم والأسبوع، توزيع حسب المجال |
| **اليوميات** | مزاج اختياري (بدون قيمة افتراضية)، رسم آخر 7 أيام، بحث ووسوم |
| **صندوق الأفكار** | Kanban بمراحل **محفوظة في قاعدة البيانات** (تتزامن بين الأجهزة)، تحديثات مؤرخة، تحويل لمهمة/مشروع |
| **الحكمة وتطوير الذات** | 7 تصنيفات، **وسوم ومجموعات**، مفضلة، اختيار اليوم، وضع قراءة كامل مع تشغيل تلقائي |
| **المشتريات** | تكلفة تقديرية مقابل المدفوع فعليًا، **تاريخ شراء حقيقي**، مصروف الشهر حسب التصنيف |
| **المراجعة الأسبوعية** | مؤشرات ومقارنة بالأسبوع السابق، المجالات المهملة، **أسئلة مراجعة موجهة**، تحويل الأولويات لمهام |
| **خريطة الحياة** | شجرة تفاعلية: مجال ← رؤية ← هدف ← مشروع ← مرحلة ← مهمة + العادات |
| **البحث العام** | Ctrl/⌘ + K، يبحث في كل شيء مع دعم تطبيع العربية |
| **الإعدادات** | عربي/إنجليزي (RTL/LTR)، فاتح/داكن، بداية الأسبوع (السبت افتراضيًا)، العملة |

### نواقص التقرير التي تم حلها في التصميم الجديد
- فصل **Life Areas** عن تصنيفات المهام/العادات/الأفكار/المشتريات (جدول `categories` مستقل).
- **Sub-projects** عبر `projects.parent_id`.
- **ملاحظات مستقلة للمشروع** (`project_notes`) و**وصف لكل مرحلة**.
- **خطوات الروتين** للعادات (`habits.steps`).
- **ملاحظات لعنصر الجدول** (`plan_items.notes`) — وتعديل الموعد لا يغيّر موعد العادة أو تاريخ استحقاق المهمة.
- **تاريخ شراء حقيقي** (`shopping_items.purchased_at`).
- **Tags وCollections** للحكمة.
- **مراحل الأفكار متزامنة** بدل Local Storage.

## هيكل الكود
```
lib/
  main.dart                 نقطة البداية
  router.dart               التنقل (go_router) + حماية تسجيل الدخول
  core/                     الثيم، الترجمة، الإعدادات، أدوات التاريخ والبحث
  data/
    models.dart             نماذج البيانات
    repo.dart               طبقة CRUD عامة على Supabase (تحديث فوري Optimistic)
    derived.dart            حسابات التقدم والعادات والإحصائيات الأسبوعية
  widgets/                  الهيكل (Sidebar / Bottom bar)، البحث، المكونات المشتركة
  features/<قسم>/           شاشة لكل قسم
supabase/schema.sql         قاعدة البيانات كاملة
```

**التقنيات:** Flutter 3 · Riverpod · go_router · Supabase (PostgreSQL + Auth) · fl_chart · Google Fonts (Cairo / Inter).
